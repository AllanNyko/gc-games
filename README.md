# GC Games

Projeto de jogo 3D para Android em fase de concepção.

## Diretrizes

- Direção criativa, narrativa e decisões de jogabilidade pertencem ao idealizador do projeto.
- Sugestões da equipe/assistente não constituem decisões aprovadas.
- Primeira visão exploratória: defesa de um local contra hordas, com câmera elevada na exploração e sobre o ombro ao mirar.
- 1–2 jogadores em celulares Android é objetivo futuro, sem arquitetura multiplayer aprovada.
- Engine candidata: Godot; detalhes técnicos serão validados por protótipos.
